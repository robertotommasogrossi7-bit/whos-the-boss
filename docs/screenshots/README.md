# Screenshots

I 4 file qui sotto sono **già referenziati** nei README (`README.md` / `README.it.md`): appena li
metti in questa cartella, la tabella screenshot si accende da sola — nessuna modifica al README.

Scattali dal telefono (hai la build installata), poi trascinali qui con **questi nomi esatti**:

| File | Cosa mostrare |
|---|---|
| `home.png` | Home "Segna partita" con la GameBar in alto (magari con un paio di giochi/partite già segnate). |
| `standings.png` | Classifica: lega o globale "La tua situazione" (bella piena, con qualche nome). |
| `poker-table.png` | Il tavolo poker live (tema feltro) — è la schermata che colpisce di più. |
| `debts.png` | La schermata Debiti "chi paga chi" (il settlement automatico). |

Suggerimenti per rendere bene:
- **Prima crea un po' di dati finti divertenti** (una lega con 4-5 amici, qualche partita): gli
  screenshot vuoti non vendono.
- Schermate **mobile** (verticali) — è un'app mobile-first.
- Se vuoi, ritaglia via la barra di stato del telefono (ora/batteria) per un look più pulito.
